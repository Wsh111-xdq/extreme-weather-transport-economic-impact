# Extreme Weather–Transport–Economic Impact

This repository contains code supporting the manuscript:

**"Coupled transport and supply-chain networks amplify economic losses from extreme weather"**

The computational framework integrates traffic-flow prediction,
counterfactual weather analysis, OD estimation, transport-network disruption,
and dynamic multi-regional input-output analysis.

## Code structure

- `traffic_prediction/`: spatiotemporal traffic prediction and counterfactual analysis
- `od_estimation/`: regional OD estimation and traffic assignment
- `economic_impact/`: dynamic economic impact simulation
- `scenario_analysis/`: hazard duration, intensity, and spatial exposure scenarios

## Data

Some input datasets are obtained from third-party or official sources and
cannot be redistributed directly in this repository. Data sources and
preprocessing requirements are described in the manuscript and Supplementary
Information.

## Reproducibility

Additional scripts and documentation will be added as the code package is
prepared for full reproducibility.
